# Limites connues de la bêta 0.6.0

Cette liste n’est pas une liste de bugs confirmés ; elle indique surtout ce qui n’a
pas encore été validé sur une durée suffisante.

- les très longs manuscrits (plusieurs dizaines de chapitres / plusieurs centaines de
  milliers de mots) doivent encore être testés en usage quotidien ;
- les exports ont été validés sur des projets de taille intermédiaire, mais doivent
  encore être éprouvés sur un livre complet ;
- l’IA « manuscrit entier » limite volontairement la quantité de texte transmise en
  une seule requête ; le traitement par lots viendra si l’usage le justifie ;
- la distribution officielle Windows par installateur n’est pas encore la version
  bêta actuelle : le lancement se fait encore depuis le dossier de développement ;
- Linux et macOS sont prévus, mais cette bêta est testée sous Windows en priorité ;
- les extensions tierces sont une API v1 jeune : les plugins doivent être testés avec
  prudence même s’ils sont isolés du cœur du manuscrit.
