# Correcteur français — Grammalecte pour Écrivain

Version 0.3.0.

Cette extension embarque le moteur JavaScript officiel Grammalecte 2.3.0 fourni par l’utilisateur, ses données grammaticales et son dictionnaire français.

Fonctions : correcteur grammatical et orthographique, **corrections appliquées uniquement après clic de l’auteur**, lexicographe, conjugueur et formateur typographique. Les corrections passent par l’API contrôlée d’Écrivain et créent l’historique normal du chapitre.

Le moteur Grammalecte reste sous GNU GPL v3 ou ultérieure. L’intégration Écrivain est distincte du cœur de l’application.
