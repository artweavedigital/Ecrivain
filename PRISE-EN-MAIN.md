# Écrivain — prise en main rapide

Écrivain est conçu pour être utilisable sans connaissances techniques.

## 1. Créer un projet

Dans **Fichier → Nouveau projet…**, choisissez un dossier et donnez un titre au
projet. Écrivain crée lui-même sa structure de fichiers.

## 2. Écrire

Créez un chapitre avec **Chapitres → Nouveau chapitre…**. Cliquez sur son titre dans
la colonne de gauche puis écrivez dans la zone centrale.

- `Ctrl+S` : enregistrer ;
- `Ctrl+F` : rechercher dans le chapitre ;
- `Ctrl+H` : remplacer dans le chapitre ;
- `F6` : afficher/masquer les caractères invisibles ;
- `F11` : plein écran ;
- `Échap` : quitter le plein écran ;
- `Ctrl +` / `Ctrl -` : zoom.

## 3. Organiser les chapitres

Déplacez-les directement à la souris. Un chapitre peut devenir sous-chapitre et
inversement depuis le menu **Chapitres** ou le menu contextuel au clic droit.

## 4. Garder ses documents à portée de souris

**Projet → Notes** permet de conserver textes, PDF, images et autres documents dans
le dossier du projet. Cliquer sur une pièce jointe l’ouvre dans l’application Windows
associée.

## 5. Préparer le roman

Vous pouvez utiliser :

- **Synopsis global** ;
- **Synoptique** ;
- **Chronologie** ;
- **Carte mentale** ;
- **Statistiques**.

Aucun de ces outils n’est obligatoire pour écrire.

## 6. Exporter

Dans **Fichier → Exporter**, choisissez Markdown, DOCX, ODT, EPUB ou PDF. Les
paramètres de mise en page se règlent dans **Projet → Configuration du document**.

## 7. En cas de problème

Écrivain conserve un historique et cinq sauvegardes du projet. Si un comportement
anormal apparaît, utilisez **Aide → Créer un rapport de diagnostic…**.
